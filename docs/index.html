autoCheck

개인적으로 사용하는 출퇴근 자동화 프로그램입니다.

서비스 개요

autoCheck는 GitHub Actions에서 정해진 시간에 실행되어 Google Calendar의 일정 정보를 확인하고, 필요한 경우 회사 그룹웨어의 출퇴근 처리를 자동화합니다.

Google 사용자 데이터

Google Calendar API를 통해 본인의 캘린더 일정 정보를 출퇴근 처리 여부 판단 목적으로만 사용합니다. Google 사용자 데이터를 판매하거나 광고 목적으로 사용하지 않으며 제3자에게 제공하지 않습니다.
