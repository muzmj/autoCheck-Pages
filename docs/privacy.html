autoCheck 개인정보처리방침

시행일: 2026-10-06

1. 개요

autoCheck는 개인이 자신의 출퇴근 업무를 자동화하기 위해 사용하는 프로그램입니다. 일반 공개 서비스나 다수의 사용자를 대상으로 하는 서비스가 아닙니다.

2. 수집 및 이용하는 정보

autoCheck는 Google Calendar API를 통해 사용자가 승인한 Google 계정의 캘린더 일정 정보를 읽을 수 있습니다. 이 정보는 휴가, 공휴일 및 기타 일정 여부를 확인하여 출퇴근 자동화 실행 여부를 판단하는 목적으로만 사용합니다.

3. Google 사용자 데이터의 이용

Google 사용자 데이터는 출퇴근 자동화에 필요한 범위에서만 사용합니다. 데이터를 광고, 프로파일링, 판매 또는 제3자 제공 목적으로 사용하지 않습니다.

4. 저장 및 보호

Google OAuth 인증 정보는 자동화 실행을 위해 필요한 비밀정보로 취급하며 공개 저장소의 소스 코드에 포함하지 않습니다. GitHub Actions에서는 GitHub Actions Secrets를 사용하여 인증 정보를 관리합니다.

5. 제3자 제공

Google 사용자 데이터를 제3자에게 판매하거나 임대하지 않습니다. 출퇴근 자동화에 필요한 그룹웨어 접근과 결과 알림 등 프로그램의 기능 수행 과정에서 필요한 요청 외에는 데이터를 공유하지 않습니다.

6. 데이터 보관

autoCheck는 Google Calendar 데이터를 별도의 데이터베이스에 장기간 저장하는 것을 목적으로 하지 않습니다. 자동화 실행에 필요한 정보를 확인한 후 결과 처리에 사용합니다.

7. 사용자의 권리 및 문의

이 프로그램은 단일 사용자를 위한 개인용 프로젝트입니다. Google 계정에서 OAuth 권한을 철회하면 autoCheck의 Google Calendar 접근을 중단할 수 있습니다.

8. 정책 변경

프로그램의 데이터 처리 방식이 변경되는 경우 이 페이지의 내용을 업데이트합니다.
